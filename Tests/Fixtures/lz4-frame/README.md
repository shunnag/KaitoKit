# LZ4 frame fixtures

The input bytes belong to this project. `generate.py` builds deterministic patterned,
xorshift32, empty, and USTAR inputs, compresses them with the **LZ4 1.10.0 CLI**, and
independently decodes every generated archive with that CLI. The manifest records the
commands, archive SHA-256, decoded size, and decoded SHA-256. No library implementation
source is part of the fixture or was used to implement the decoder.

The independent/dependent cases cross block boundaries. Maximum block descriptors
64 KiB, 256 KiB, 1 MiB, and 4 MiB, stored blocks, block/content checksums, optional
content size, and empty content are covered. `no-checksum` lets payload mutation reach
the raw decoder rather than being rejected by an earlier block checksum.

Six `legacy-*` fixtures use the CLI's `-l` option: empty, tiny, exactly 8 MiB,
8 MiB plus 53 bytes, incompressible, and USTAR. `LZ4LegacyTests` also creates an
8 MiB plus 17 byte xorshift32 input at runtime, and independently encodes/decodes it
with the CLI so a block larger than 8 MiB on disk need not be committed as a fixture.

Legacy framing has no checksum or declared size. It cannot detect the removal of
whole trailing blocks. Tests reject truncation within a block and explicitly accept
EOF at a complete block boundary. The public specification's four-zero-byte Linux
end marker is accepted, although LZ4 1.10.0 CLI rejects it. The CLI also rejects a
legacy frame following a modern frame; KaitoKit handles either concatenation order.
The CLI comparison covers legacy-to-modern and legacy-to-legacy sequences. Short
intermediate legacy blocks are accepted for compatibility with that CLI.

`xxh32_vectors` are taken from the CLI's content-checksum footer for the byte sequence
`(i * 73 + 19) & 255` at each recorded length. Tests compare one-shot and incremental
updates, including nonzero slice indices. These values are not generated by KaitoKit.

Specification inputs:

- [LZ4 Frame Format v1.6.4](https://github.com/lz4/lz4/blob/dev/doc/lz4_Frame_format.md)
- [LZ4 Block Format, revised 2022-07-31](https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md)
- [XXH32 algorithm, xxhash_spec v0.2.0](https://github.com/Cyan4973/xxHash/blob/release/doc/xxhash_spec.md)

Regenerate with `python3 Tests/Fixtures/lz4-frame/generate.py` from the repository root.
