# 7z Swap2 / Swap4 fixtures

Project-owned byte sequences generated by `generate.py` and compressed by 7-Zip
26.03 (arm64). No third-party archive or codec implementation source is included.
The method IDs `02 03 02` and `02 03 04` come from the official
[Methods.txt](https://github.com/ip7z/7zip/blob/main/DOC/Methods.txt).

Each archive has one solid group containing `first.bin` (262,403 bytes) and
`second.bin` (1,027 bytes), plus an empty file. The first member exceeds the
256 KiB input buffer and ends partway through a Swap unit. The Swap4 solid stream
also ends with two remaining bytes. The `aes` variants encrypt both data and
headers; `KaitoFixture` is a public fixture password.

The generator checks the solid/filter listing and independently extracts every
entry with `7zz x -so`, comparing all bytes. `manifest.json` records SHA-256 of the
archives and original entries, tool version, and command arguments. Regeneration
changes timestamps and random encryption parameters, so archive hashes can
change; entry hashes must not.

`SevenZipSwapTests` additionally records packed outputs for inputs `0..<N`,
N = 0...9, generated with `-m0=Swap2` / `-m0=Swap4`, `-m1=Copy`, `-mhc=off` and
`-ms=off`. The raw packed bytes begin at offset 32. These establish the complete
unit reversal and unchanged final partial unit independently of KaitoKit.

```sh
python3 Tests/Fixtures/sevenzip-swap/generate.py
swift test --filter SevenZipSwapTests
```
