# XZ RISC-V filter の実装と検証 — 2026-11-02

## 範囲と実装

XZ の RISC-V filter（ID `0x0B`）に対応した。変換規則は新たな実装資料を増やさず、
[7z側の black-box 導出](2026-11-02-sevenzip-riscv.md)で検証した `BCJFilterDecompressor` を
そのまま使う。XZ container / block header / Index / check は公開 `xz-file-format.txt` と
既存の `XZResourceValidator` / `XZNativeDecompressor` の契約に従う。

- `XZStreamLayout.Block` は前置 RISC-V filter の有無を保持する。filter properties は 0 byte
  以外を malformed とする。
- block ごとの LZMA2 decoder の出力を `.riscv` filter に通す。開始位置は block ごとに 0 で、
  check は逆変換後の byte に対して計算する。Index と元の check field は既存の検証を使う。
- RISC-V を含む stream は native の直列復号に限定する。並列 job と、失敗時の Apple Compression
  への再生は使わない。
- `XZDecompressor` も同じ native 経路へ委譲するため、単体 XZ、圧縮 tar、ZIP / XAR / PBZX の
  既存入口が同じ実装を通る。
- x86 + RISC-V のような連結 stream では、RISC-V でない前置 filter の block を単一 block の
  synthetic XZ stream として Apple Compression に渡し、RISC-V block を native で復号する。
  元の Index と block check は外側で検証する。

RISC-V 以外の並列・再生経路は変更していない。

## XCTest

- `XZResourceLimitTests`: 単体 `riscv.xz` と `riscv.tar.xz` の payload が原本と一致すること、
  `x86.xz + riscv.xz` の連結が 2 回分の payload になることを確認する。
- `ParallelXZDecompressorTests`: 既存 fixture に加え、RISC-V 向けの 4,096 byte 命令 vector を
  100 回繰り返した 409,600 byte を 64 KiB block にした入力を使用する。複数 block の位置補正が
  正しく、worker を使わず、check 破損で Compression へ再生しないことを確認する。
- `.tar.xz` の chunk map が serial / staging で一致することも検査する。

実行結果:

- `swift test -j 4 --filter 'XZResourceLimitTests|ParallelXZDecompressorTests'`: 23 tests、0 failures。
- `swift test -j 4 --filter XZ`: 55 tests、1 skipped、0 failures。既存の native / splice / ZIP / XAR
  回帰を含む。

## CLI と独立 oracle

`xz -dc` を独立 oracle にし、`kaito sha` のサイズと SHA-256 を原本と照合した。tar では `xz` の
出力が tar 本体、KaitoKit の entry 出力が tar 内 payload なので、それぞれの期待値を分けた。

| 入力 | 展開後の確認 |
| --- | --- |
| `riscv.xz` | 1,984 byte の payload が一致 |
| `riscv.tar.xz` | 1,984 byte の tar 内 payload が一致 |
| `x86.xz + riscv.xz` | 3,968 byte の連結 payload が一致 |
| RISC-V、64 KiB 複数 block、check = none / crc32 / crc64 / sha256 | 各 409,600 byte が一致 |

各書庫は `xz -dc` の出力も原本と全 byte 一致した。複数 block の payload SHA-256 は
`55b625358eaa0bd2df809d5c491e9f6d79d954ac1880cef2dede0e09629be83a`。

`TZ=UTC KAITOKIT_WRITE_TAR_GOLDEN=1 swift test -j 4 --filter TarPublicValueGoldenTests`:
